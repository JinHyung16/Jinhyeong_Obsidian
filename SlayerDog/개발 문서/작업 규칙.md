## §1. 이 프로젝트를 움직이는 것

| 무엇 | 어떻게 |
|---|---|
| 데이터 빌드 | `cd _DataExporter && node export.js` |
| 아트 생성 | `python _DataExporter/tools/build_<대상>.py` 후 `build_meta.py` (안 돌리면 GUID 가 새로 잡혀 참조가 끊긴다) |
| 에디터 작업 | `Temp/editor.task` ← `build` `validate` `nodes` `refresh` `ui` `sceneui` `star` `starsave` `staredit` `buildwin` `locsync` `locexport` `lang_ko` `lang_en`. 결과 `Temp/editor.task.log` |
| 플레이 검증 | `Temp/runloop.request` ← `god:60` / `mortal:820:<주인공>:-1:<맵>:<시드>:<성장>:<투어 간격>:<촬영 시작>:<촬영 끝>`. 결과 `Temp/runloop.report` + `runloop_*.png` |
| 스팀 이미지 · 트레일러 | `build_promo.py` → `build_trailer.py` (Docs/steam) |

- `Temp/` 는 에디터가 떠 있을 때만 있다. 에디터가 떠 있으면 배치모드는 프로젝트 잠금으로 실패한다
- 하네스가 걸리면 `Temp/editor.stop` 으로 Play 모드만 끈다. 에디터 자체를 재실행하지 않는다
- 밸런스 일괄: `bash _DataExporter/tools/run_batch.sh "<시드>" "<주인공>" <맵>` → `python _DataExporter/tools/summarize_batch.py`. 일괄 중에는 Assets 를 건드리지 않는다 (판마다 새로고침된다)
- 작업 문서는 볼트에 둔다 (저장소에 올리지 않는다): 큐 [[작업 큐]] · 스펙 [[스펙]]. 지난 작업 기록은 남기지 않는다
