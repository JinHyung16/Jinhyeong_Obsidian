# 검증 단계

상위: [PD](PD.md)

## QA 체크 순서

### 요약

- PD QA 는 안 된 것을 찾아 나열하는 일이다. 만들지 않는 것은 R17 이다.
- 아래 순서와 「판정」 열은 기본 점검 방법이다.
- 상황에 맞는 더 정확한 방법이 있으면 고르되, 아래 규칙 세 줄은 그대로다.

### 규칙

#강제 [원칙 R6](원칙.md#R6) 미측정 항목은 미흡이다(함정: [배치 종료에 잘린 비동기 에디터 작업](함정%20-%20도구%20러너.md#배치%20종료에%20잘린%20비동기%20에디터%20작업)).

#강제 [원칙 R7](원칙.md#R7) 판정은 결과물에서 되읽은 것만 센다. 세는 검사는 최소 개수를 박는다(함정: [프로젝트 설정에 반영 안 된 확정표](함정%20-%20설정%20빌드.md#프로젝트%20설정에%20반영%20안%20된%20확정표) · [어긋난 엔진 설정 짝 구성요소](함정%20-%20설정%20빌드.md#어긋난%20엔진%20설정%20짝%20구성요소) · [편집 모드에서 실패한 UI 레이캐스트](함정%20-%20검사기%20설계.md#편집%20모드에서%20실패한%20UI%20레이캐스트) · [폭 하나로만 맞춘 기준 해상도](함정%20-%20UI%20흐름.md#폭%20하나로만%20맞춘%20기준%20해상도)).

#강제 [원칙 R8](원칙.md#R8) 이관율 대조표 없이 100% 는 선언하지 않고, 겉 점수가 100% 여도 G8 이 안 닫히면 미흡이다(함정: [재생 전용 호출이 박힌 프레임워크 골격](함정%20-%20도구%20러너.md#재생%20전용%20호출이%20박힌%20프레임워크%20골격) · [레이아웃 그룹 자식에 붙인 크기 자기결정 부품](함정%20-%20UI%20흐름.md#레이아웃%20그룹%20자식에%20붙인%20크기%20자기결정%20부품)).

### 설계

| # | 보는 것 | 판정 |
|---|---|---|
| 0 | 역할 경계 위반 | 학습 회차 Assets 변경 · ②에서 배선 · PD 직접 제작 ([PD - 실행 단계](PD%20-%20실행%20단계.md) 「역할 기동 규약」) |
| 1 | 게이트([PD - 게이트](PD%20-%20게이트.md)) G0~G8 순서대로 닫혔나 | 아래층이 안 닫혔으면 위층 점수는 무효 |
| 2 | 플로우 diff([PD - 게이트](PD%20-%20게이트.md) 「플로우 diff」) | 없어야 할 창 · 있어야 할 창 · 순서 |
| 3 | 전수 대조표([PD - 인수인계 계약](PD%20-%20인수인계%20계약.md) 「전수 대조표」) 빈 칸 | 빈 칸 = 미이관 |
| 4 | 수치 판정. 정답지 또는 A/B 개체 수(공통절차 「A/B 측정」) | 상태를 맞춘 뒤에 잰다 |
| 5 | 렌더 판정. 글자 제외 점수, 그리기 파라미터 표 | 점수가 낮으면 공통절차 「점수를 믿기 전에」부터 |
| 6 | 리소스 감사(공통절차 「에셋 등록은 양방향으로 감사한다」) | 코드가 요구하는 주소가 있는가 (양방향) |
| 7 | 거동 판정. Play Mode 에서 눌러 본다 | 클릭 가능성·상태 전이·지연 로드 아트 |
| 8 | 재측정 대기 표 | 미측정 항목을 그대로 미흡 목록에 편입. 담당자가 안 올려도 PD 가 집는다 |
| 9 | 이관율 대조표 (분석로직 「이관율 대조표」) | 분모 = 확정표 범위. 「의도된 차이」 밖 차이는 전부 미흡. 표가 없으면 100% 선언 불가 |
| 10 | 「증명」 열이 채워졌나 | 갈래마다 화면에 나옴/동작함의 근거. 「프리팹에 있다」·「표에 행이 있다」는 증명이 아니다. 빈 줄은 분자에서 뺀다 (함정: [만든 것을 옮긴 것으로 센 이관율 분자](함정%20-%20판정%20보고.md#만든%20것을%20옮긴%20것으로%20센%20이관율%20분자)) |
| 11 | 개체마다 행동이 분모에 들어갔나 | 소스 개체 클래스 `update()` 분기 수 = 우리 갈래 수. 사례: 공격 못 하는 동료가 100% 였다 (함정: [개체만 세고 행동은 안 센 분모](함정%20-%20판정%20보고.md#개체만%20세고%20행동은%20안%20센%20분모)) |
| 12 | 검사가 결과물을 재나 | 여러 패스·캐시 제자리 수정·좌표 변환은 중간값이 맞아도 결과가 갈린다. 골든은 산출물 전 칸 대조 (함정: [순수 함수만 잰 골든 테스트](함정%20-%20검사기%20설계.md#순수%20함수만%20잰%20골든%20테스트)) |
| 13 | 세는 검사가 개수를 못 박았나 | 「0개 실패」는 분모 0 이어도 통과로 보인다. 최소 개수를 박고 만들어 둔 것 전부(프리팹·표)를 센다 (함정: [검사 분모를 지금 보이는 화면에 맡긴 검사기](함정%20-%20판정%20보고.md#검사%20분모를%20지금%20보이는%20화면에%20맡긴%20검사기)) |
| 14 | 그림으로 못 읽는 것을 그림으로 정하지 않았나 | 층(겹침) · 늘리는 방식(9슬라이스/확대) · 「0인가 못 읽었나」는 덤프의 부모·형제 순서와 소스로 판정 (함정: [덤프에 원리적으로 없는 값을 공식으로 메운 함정](함정%20-%20원본%20관측.md#덤프에%20원리적으로%20없는%20값을%20공식으로%20메운%20함정) · [스크린샷으로 정한 화면 층](함정%20-%20UI%20흐름.md#스크린샷으로%20정한%20화면%20층)) |
| 15 | 원본과 우리의 화면 단면을 숫자로 댔나 | 값이 다 맞아도 알파·색공간·블렌딩·늘리기로 화면이 다를 수 있다. 같은 자리 한 줄을 색이 바뀌는 구간으로 뽑아 나란히 둔다 (함정: [원본만 재고 우리 화면은 안 잰 대조](함정%20-%20검사기%20설계.md#원본만%20재고%20우리%20화면은%20안%20잰%20대조)) |
| 16 | 속을 이어서 다듬을 수 있나. G8 | 네 수가 원장에 있다. 겉 점수가 100% 여도 G8 이 안 닫히면 미흡이다 ([PD - 대원칙](PD%20-%20대원칙.md) 「속 품질」) |

## 미흡 목록

### 요약

- QA 결과는 「미흡 목록」으로 낸다.
- 항목마다 [무엇이 · 어디가 · 기대 · 실측] 네 칸이 기본이다. 「어색하다」는 재현할 수 없어 결과가 되지 못한다.
- 미흡 목록이 다음 회차 리스트업이 된다. 달성률을 내리고 회차를 +1 한다.
- 미측정은 [PD - 근거 등급](PD%20-%20근거%20등급.md) 「미측정」(R6) 대로 적는다.
- 사이클은 전 항목 100% 에서 닫는다 (R8).

## PD 가 속는 것

### 요약

- PD 가 가장 많이 속는 것은 셋이다.

### 설계

| 함정 | 실제 |
|---|---|
| 「화면 점수가 높다」 | 없어야 할 창이 떠 있어도 높다 ([PD - 게이트](PD%20-%20게이트.md) 「플로우 diff」) |
| 「경고 0 이다」 | 빌드 중 NRE 를 노이즈로 방치하면 기준으로 못 쓴다 (공통절차 「컴파일·툴 실행 순서」) |
| 「구간 점수가 낮으니 결함이다」 | 영상 프레임·재화 보유량 차이일 수 있다 (공통절차 「A/B 측정」 상태 정합표) |
