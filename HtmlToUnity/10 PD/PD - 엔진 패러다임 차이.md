# 엔진 패러다임 차이

상위: [PD](PD.md)

## 새는 일곱 자리

### 요약

- 대원칙을 지켜도 새는 자리가 일곱이다.
- 기본은 착수 전에 읽고 각 행의 점검을 회차마다 한 번 돌리는 것이다 (G7).
- 아래 처방은 기본값이다. 게임 구조에 더 맞는 Unity 방식이 있으면 고른다.

### 설계

| # | HTML5 | Unity | 파생 결함 |
|---|---|---|---|
| 1 | 즉시 모드. `innerHTML=` 로 매번 다시 그린다 | 유지 모드. 오브젝트를 살려 두고 값만 바꾼다 | 이전 상태 잔존 · 이벤트 중복 구독 · 캐시 무효화 누락 |
| 2 | 문서 순서. 나중에 쓴 것이 위 | 형제 순서. 풀링이 순서를 뒤집는다 | 선이 노드 위로 · 딤이 대상 아래로 |
| 3 | 캐스케이드. `var(--nc)` 하나로 자식 전부 | 개별 대입. Graphic 마다 따로 | 한 요소만 기본색 · 상태색 누락 |
| 4 | 이벤트 위임. 컨테이너 1개 + `closest()` | 개별 리스너. 노드마다 Button | 노드 2000개 = GameObject 2000개 |
| 5 | 흐름 배치. 내용이 자리를 만든다 | 고정 rect. 자리가 내용을 자른다 | 넘침·잘림 |
| 6 | 공짜 자원. 아무 글리프·아무 색 | 선언된 것만. 폰트 cmap · Linear | 두부 · 빈칸 · 알파 과다 |
| 7 | 느슨한 수치. 전부 double, `Infinity` | 엄격. float 혼입, `int.MaxValue` | 정밀도 손실 · `2147483647` 노출 |

## 유지 모드

### 요약

- 「안 그림」과 「안 끔」은 다르다.
- 원본에 `else` 가 없어도 우리에겐 `else` 가 필요하다. 끄기 · 구독 해제 · 캐시 무효화가 그것이다.
- 정본은 UIFramework 「「안 그림」과 「안 끔」은 다르다」이고, 점검은 G7 이다.

## 형제 순서

### 요약

- 풀링이 순서를 뒤집는다.
- 같은 부모에 섞어 `Instantiate` 하면 먼저 만든 것만 뒤로 간다.
- 기본 처방은 먼저 그린 것에 전용 부모를 만들어 `SetAsFirstSibling` 으로 고정하는 것이다.

## 개별 대입

### 요약

- 색은 한 곳에서 받아 뿌린다.
- 상태색 컴포넌트는 색을 받는 진입점을 하나 두고 거기서 전부 뿌리는 것이 기본이다.
- 이유: 진입점이 여럿이면 한 요소만 기본색으로 남는다.

### 설계

```bash
# 점검 — 원본이 한 요소에 몇 개의 상태 클래스를 거는지 센다
grep -o "\.tnode\.[a-z-]*" 원본.html | sort -u
```

## 개별 리스너

### 요약

- 개수를 먼저 센다.
- `closest()` 는 개체 수 상한이 없다는 뜻이다.
- 적으면 Button 이 기본이다. 수백을 넘으면 Button 대신 뷰 하나가 좌표로 찾는 편이 낫다.

## 고정 rect

### 요약

- 흐름 배치를 고정 rect 로 옮기면 길이가 변하는 순간 전부 깨진다.
- 깨지는 순간은 번역 · 큰 수치 · 긴 이름이다.
- 정본은 UI/UX 「CSS 흐름을 고정 박스로 옮기면 길이가」.

## 선언된 자원

### 요약

- 원본이 공짜로 쓰던 자원은 Unity 에서 선언된 것만 쓸 수 있다.
- 유니코드 기호 · 반투명 합성 · 임의 폰트 셋을 점검한다.

### 설계

| 원본이 공짜로 쓰는 것 | Unity 에서 필요한 선언 | 점검 |
|---|---|---|
| 유니코드 기호 | 폰트 cmap 에 있거나 `TMP_SpriteAsset` 등록 | 기호 전수 → cmap 대조 (`ResourceRule` 「원본의 기호는 셋 중 하나로 갈린다」 · G7 #4) |
| 반투명 합성 | Linear 면 브라우저와 다르게 합성된다 | 알파 역산. 밝은 것과 어두운 것은 방향이 반대다 (`Fx` 「색공간」 · 함정: [어두운 오버레이 알파 역산 방향 착오](함정%20-%20아트%20굽기.md#어두운%20오버레이%20알파%20역산%20방향%20착오)) |
| 임의 폰트 | 폰트 하나 · 폴백 없음 | UIUX 「주폰트는 가장 넓은 글리프 집합이 가져간다」 |

## 엄격한 수치

### 요약

- JS 숫자는 전부 double 이다. 기본은 double 유지다.
- 이유: `float` 가 섞이면 일곱 자리 표 7행의 정밀도 손실이 난다.

### 설계

- `Infinity` 는 표기 분기를 같이 옮긴다 (UI/UX 「`Infinity` 는 표기 분기를 같이 옮긴다」).
- 가중 추첨 누적도 `float` 대신 double 로 두는 것이 기본이다.
