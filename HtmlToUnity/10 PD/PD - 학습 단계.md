# 학습 단계

상위: [PD](PD.md)

## 학습 단계

### 요약

- 지식 담당자가 원본을 돌려 보고 `HtmlToUnityLogic/` 을 채우는 단계다.
- PD 확정에서 지식 담당자 수행까지가 학습 단계다.
- 산출물 위치는 `<원본폴더>/HtmlToUnityLogic/` 이다. 확정표 8번의 원본 폴더 최상위 바로 아래이고 Assets 밖이다.

### 규칙

#강제 [원칙 R17](원칙.md#R17) 학습 단계의 지식 역할은 Unity 코드·산출물을 만들지 않는다.

### 설계

- 기본은 캡처를 쌓지 않고 장면 그래프 덤프를 남기는 것이다 (공통절차 「캡처는 쌓지 않는다」).
- 부득이한 캡처에는 상태를 같이 적는다.
- 파일별 골격·기입 규칙은 [분석로직 「HtmlToUnityLogic/」](분석로직.md).

## 돌려 보기

### 요약

- 학습은 「읽기」가 아니라 「돌려 보기」다.
- HTML5 를 실제로 실행해 놀아 본다.
- 기존 기록은 「전 회차: … / 이번 회차:」로 남긴다 (R23).
- 자기가 지난 회차에 쓴 문장을 의심한다.

## 오염된 내용

### 요약

- 오염은 사실이 아닌데 사실로 기록되어 다음 회차의 전제가 된 것이다.
- 이것들이 원장에 기록되어야 하는 것이다.
- 오염을 발견하면 고치기 전에 원장에 먼저 적는 것이 기본이다. 이유: 고친 뒤에는 무엇이 오염이었는지가 사라진다.

### 설계

| 갈래 | 예 |
|---|---|
| 캡처를 사양으로 삼음 | 두 줄로 보여 `LR` / `LEGEND RARE` 두 요소로 적었는데 DOM 은 한 덩어리였다 |
| 문서·라인 번호를 믿음 | 기획서 라인 번호가 구간마다 어긋났다 (공통절차 「문서의 라인 번호를 믿지 마라」) |
| 애니메이션 한 프레임을 정색으로 오인 | 점멸 중 캡처로 `#8a3a35` 를 구웠다. 원본은 `#ff5a4d` |
| 이름이 비슷한 다른 물건 | `XXX_button.png` 를 행 배경으로 깔았는데 장착 버튼용이었다 |
| 추측을 결론으로 적음 | 「대략 이 정도 배율」이 원본 수치처럼 인용됐다 |
