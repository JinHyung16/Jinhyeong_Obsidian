# 노트 형식

이 볼트의 모든 노트가 따르는 틀이다. 찾아 읽는 책이라 형태를 하나로 맞춘다.

## 뼈대

### 요약

- 노트 하나는 제목과 카테고리 여러 개로 이루어진다.
- 카테고리 안은 요약 · 규칙 · 설계 차례다.
- 규칙이 없는 카테고리는 규칙 절을 뺀다.

### 규칙

- 제목은 `# 명사` 한 덩어리로 쓴다. 제목에 설명을 붙이지 않는다.
- 카테고리는 `## 명사` 로 쓴다. 검색창에 칠 말을 쓴다.
- 절 이름은 `### 요약` · `### 규칙` · `### 설계` 로 고정한다. 다른 이름을 만들지 않는다.
- 제목 아래에 한 줄 설명만 둘 수 있다. 두 줄부터는 카테고리로 내린다.

### 설계

| 절 | 무엇을 적나 | 길이 |
|---|---|---|
| 요약 | 이 카테고리가 무엇인지, 결론이 무엇인지 | 글머리 2~5줄 |
| 규칙 | 지켜야 하는 것. 강제는 [원칙](원칙.md) 링크와 `#강제` 태그로 단다 | 글머리 또는 표 |
| 설계 | 어떻게 만드나. 표 · 값 · 파일 경로 · 이유 | 표를 먼저 쓴다 |

## 문장

### 규칙

- 한 문장에 한 가지만 담는다.
- 줄표로 설명을 잇지 않는다. 문장을 끊는다.
- 겹화살괄호 강조를 쓰지 않는다. 필요하면 굵게 쓴다.
- 인용부호 「」 는 화면에 그대로 뜨는 글자에만 쓴다.
- 사실 뒤에 근거를 `[소스] 파일:조각` 또는 `[실측] 언제·무엇` 으로 단다.

### 설계

| 피할 것 | 대신 |
|---|---|
| `## Canvas 설정. 한 번 정하고 바꾸지 않는다` | `## Canvas 설정` 아래 규칙 줄에 「한 번 정하고 바꾸지 않는다」 |
| `값은 «항상» 같다` | `값은 항상 같다` |
| 한 줄에 사실 세 개 | 글머리 세 줄 |

## 쪼개기

### 요약

- 한 노트에 다 넣지 않아도 된다.
- 카테고리가 길어지면 하위 노트로 뺀다.
- 상위에는 요약과 링크만 남긴다.

### 규칙

- 카테고리 하나가 화면 한 장(약 60줄)을 넘으면 하위 노트로 뺀다.
- 하위 노트 이름은 `상위 - 카테고리` 로 짓는다.
- 하위 노트 앞머리에 `상위: [상위 노트](상위%20노트.md)` 한 줄을 둔다.
- 같은 사실은 한 노트에만 둔다. 다른 노트는 링크한다.

### 설계

| 상황 | 어떻게 |
|---|---|
| 카테고리가 길다 | 하위 노트로 빼고 상위에 요약 3줄과 링크 |
| 표가 길다 | 표만 하위 노트로 빼고 상위에 열 이름과 링크 |
| 두 노트가 같은 말을 한다 | 정본을 하나 고르고 나머지는 링크 |

## 링크

### 규칙

- 링크는 `[보일 글](파일%20이름.md)` 로 쓴다. 볼트 안에서 파일 이름은 유일하다.
- 헤딩까지 가리킬 때는 `[보일 글](파일.md#카테고리)` 로 쓴다.
- 링크가 가리키는 헤딩이 실제로 있어야 한다.

### 설계

- 노트를 쪼개면 [지도](지도.md) 와 상위 노트의 링크를 같이 고친다.
- 함정 노트를 쪼개면 [함정 색인](함정%20색인.md) 의 항목 수도 같이 고친다.

## 앞머리

### 규칙

- 모든 노트에 `분류` · `성격` · `tags: htmltounity` 를 둔다.
- `성격` 은 강제 또는 방향이다. 강제는 [원칙](원칙.md) 과 이 노트뿐이다.
- 하위 노트는 상위와 같은 분류를 쓴다.
