# 정답지와 채점기

상위: [Transfer_Programmer](Transfer_Programmer.md)

## 정답지

### 요약

- 정답지는 그래픽이 아니라 숫자다. 그림과 무관하다.
- 그림이 같아도 숫자가 틀릴 수 있고 반대도 된다. 둘은 다른 검사라 둘 다 보는 것이 기본이다.
- 「입력 → 출력」 한 줄이 한 행이다. 더 복잡하면 대개 입력을 잘못 고른 것이다.

### 설계

| | 무엇을 재나 | 어디에 |
|---|---|---|
| 정답지 · 채점기 | 같은 입력에 원본이 낸 값. 좌표 · 속도 · 점수 · 시각 · 개수 | `07_기대값.md` 표 + 채점기 |
| 렌더 A/B | 그림이 같은가. 픽셀 일치율 · 색 | 캡처 대조 (별개 검사) |

정답지는 이렇게 생겼다.

```
입력                     기대 출력 (원본 실측)                    n   출처
누름 300ms · 레벨2   →   착지 x = −455.5 ± 10                    8   [관측]
점수 4연속           →   증가량 = 3 (4가 아니다 — 원본 이상)      3   [관측]
```

무엇을 정답지로 고르나.

| 고른다 | 안 고른다 |
|---|---|
| 판정이 갈리는 경계 (성공↔실패가 뒤집히는 자리) | 한가운데 값. 틀려도 안 걸린다 |
| 짧게 결판나는 입력 | 연쇄가 긴 것. 원본 자신이 흔들린다 |
| 원본이 실제로 낼 수 있는 값 | 도달 불가 값 (「심화」 ③ 참조. 정본은 공통절차 「런타임에서 직접 캐내는 법」) |
| 원본 이상(버그)이 드러나는 자리 | |

## 덤프 diff 채점기

### 요약

- 이미지 비교보다 먼저 돌린다.
- 원본 `frames/*.tsv`(사건 프레임의 씬 그래프)와 같은 사건에서 뜬 우리 덤프를 줄 단위로 diff 하는 것이 기본 채점이다.
- 우리 덤프는 재생 검사기가 창(RectTransform → 원본 논리 좌표)과 풀 렌더러를 같은 열로 뜬다.
- 경로(`paths.md`)마다 돌리는 것이 기본이다.

### 규칙

#강제 [원칙 R6](원칙.md#R6) 성공 경로만 diff 0 이면 실패 경로의 창은 미측정이다.

### 설계

- 허용 오차는 표로 적어 둔다. 좌표 ±1 · 배율 ±0.01 · 알파 ±0.01 · 문구 정확이다.
- 갈린 줄은 「무엇이 · 어디가 · 기대 · 실측」으로 찍는다.

## 채점기

### 요약

- 채점기는 일회용이다.
- 정답지는 표고, 채점기는 그 표를 읽어 주는 프로그램이다.
- 표가 남으면 채점기는 다시 만들 수 있다.

### 규칙

#강제 [원칙 R5](원칙.md#R5) ①의 정답지는 원본에서 온 값이다. 구현이 읽는 표를 그대로 읽으면 자기 채점이다.

#강제 [원칙 R6](원칙.md#R6) ④의 미측정·도달 불가는 통과로 세지 않고, 제외 건수는 늘 따로 보인다.

### 설계

| 단계 | 무엇을 |
|---|---|
| ① | 표를 코드가 읽을 형태(배열 · 리터럴)로 옮긴다 |
| ② | 한 행 = 한 판정. 입력 → 결과 → 허용치 안인가 |
| ③ | 출력은 `N/N` 과 실패한 행의 실측값 |
| ④ | 분류를 따로 센다: `통과 / 실패 / 비결정 / 도달 불가 / 미측정`. 제외 건수를 표시한다 |

## 채점기 함정

### 요약

- 채점기 자체가 틀리는 자리가 있다. 여기서 회차가 날아간다.
- 기본은 마감 전에 전 검사를 두 번 돌려 같은 답인지 보는 것이다. 갈리면 그것부터 닫는다.
- 이유: 흔들리는 검사로는 개선/악화를 판정할 수 없다.

### 설계

| 함정 | 대응 |
|---|---|
| 채점기가 비결정적 | 물리·난수 채점기는 세계를 헐고 다시 세우면 내부 순서가 바뀐다. 시행마다 새로 만든다 |
| 표본 의존 | 프레임 하나를 놓치면 실패한다. 여러 번 관측해 합집합을 쓰거나 「놓쳤다」를 실패와 다른 줄로 찍는다 |
| 기준점이 섞임 | 시각의 원점(입력 시작/발사 프레임)을 표에 명시한다 |
| 엔진 파생값을 그대로 믿음 | 접촉 법선 같은 값은 무효값이 나온다. 유효성 검사를 붙이고 무효면 다른 축으로 |

## 금지

### 요약

- 점수가 오르도록 값을 고르지 않는다.
- 실측하지 못한 계수를 정답지에 맞춰 조정하면 실측을 지어내는 것이 된다 ([원칙 R4](원칙.md#R4)).
- 정답지가 틀렸다고 보이면 원본을 다시 재서 밝히고, 정정 사유를 표에 남기는 것이 정정 경로다.

### 규칙

#강제 [원칙 R5](원칙.md#R5) 점수가 오르도록 값을 고르지 않는다.
