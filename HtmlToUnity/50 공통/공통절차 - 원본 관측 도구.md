# 공통절차 - 원본 관측 도구

상위: [공통절차](공통절차.md)

## 도구 선택

### 요약

- 도구가 입력을 바꿔 버린다. 원본을 여는 도구를 먼저 고른다.
- 원본 입력이 단발 클릭뿐이면 내장 브라우저로도 된다.
- 홀드·드래그가 있으면 외부 자동화가 기본이다.
- 기본은 도구가 되는지를 착수 때 한 번 찔러 보고 확정표 13 에 적는 것이다.

### 설계

| 함정 | 증상 | 대책 |
|---|---|---|
| 에디터 내장 브라우저(CDP)는 단발 클릭만 전달 | 누르고 있기가 0 ms 로 압축돼 홀드·드래그 입력이 안 들어간다 | `mouse.down()` → 대기 → `mouse.up()` 이 실제 시간으로 가는 외부 자동화로 연다 |
| 게임 프레임 직접 접속 | 핫링크 차단으로 흰 화면·오류 | 서비스 페이지째로 열고 프레임을 전수 순회해 찾는다 |
| `file://` | 정적 스냅샷 ([결정적 스냅샷](공통절차%20-%20원본%20관측%20도구.md#결정적%20스냅샷)) | 로컬 HTTP 서버로 연다 |

## 결정적 스냅샷

### 요약

- 원본을 결정적으로 찍어야 G4 대조의 정본이 된다.
- 렌더 대조는 두 그림이 같은 상태일 때만 뜻이 있다.
- 결정화 패치는 원본 복사본에만 건다.

### 규칙

#강제 [원칙 R21](원칙.md#R21) 결정화 패치는 원본 복사본에만 건다. 원본 폴더는 그대로 둔다.

### 설계

원본 복사본에 기본으로 다음을 적용한다.

- 난수를 시드 LCG 로 고정한다.
- 주기 호출을 빈 함수로 덮어 주기 진행을 막는다.
- 원격 리소스를 로컬 경로로 바꾼다.
- 웹폰트를 뺀다. 글자는 대조 제외 항목이다.
- 레이아웃 크기를 못 박는다.

`file://` 은 정적 스냅샷이 될 수 있다. 브라우저 패널이 프로젝트 밖 파일을 스크립트가 안 도는 스냅샷으로 열 수 있고, 화면은 멀쩡해 보인다. 기본은 로컬 HTTP 서버로 여는 것이다.

「좌표를 재는 실행」과 「그림을 찍는 실행」의 배치가 다를 수 있다. 헤드리스 브라우저는 두 실행의 창 크기가 다를 수 있다. 스크롤바와 페이지 높이가 원인이다. 기본은 캡처용 페이지에 `html, body { width: …px; height: …px; overflow: hidden; }` 로 크기를 못 박는 것이다. 좌표는 숨은 요소의 텍스트로 DOM 에 심어 덤프로 꺼낸다.

## 대기 수단

### 요약

- 하네스에 `requestAnimationFrame` 을 쓰지 않는다.
- 기본 대기 수단은 `setTimeout` 과 `setInterval` 이다.
- 이유: 창·패널이 안 보이면 rAF 가 멈추고, 타이머는 계속 돈다.

### 설계

```js
// 하지 않는다: 패널이 숨겨지면 여기서 멈춘다
await new Promise(r => requestAnimationFrame(r));

// 한다: 숨겨져 있어도 돈다
await new Promise(r => setTimeout(r, 10));
```

- 막힌 것 같으면 `document.hidden` 을 먼저 찍는다. 원본이 정말 멈췄는지는 타이머 한 번으로 확인한다.

## node 틱 정답지

### 요약

- 결정적 시뮬은 원본 번들을 node 로 돌려 틱 정답지를 만든다.
- 원본이 시드 난수와 고정 틱 시뮬을 워커 번들 하나에 두면, 화면 없이 node 에서 돌려 틱별 상태 해시를 받는 것이 기본이다.
- 플레이 관찰로는 틱 단위 대조가 안 된다.

### 설계

| 할 일 | 방법 |
|---|---|
| 워커 전역 | `self`(메시지 받기 · 보내기) · `location` 을 가짜로 둔다 |
| 네트워크 | `fetch` 를 바꿔 맵 · 설정 파일을 로컬 바이트로 준다 |
| 입력 | 원본 메시지 형식 그대로 시작 → 빈 명령 턴을 넣는다 |
| 대조 범위 | 이관이 아직 안 옮긴 시스템(AI 등)이 움직이기 전 틱까지만. 옮길 때마다 범위를 늘린다 |

- 원본 코드는 스크래치패드에서만 돌린다. 프로젝트에는 해시 같은 결과 숫자만 넣는다 (#강제 [원칙 R11](원칙.md#R11)).
- 소스를 읽어 옮긴 식도 이 대조에서 틀린 것이 나온다. 식에 있는 배율이 호출하는 쪽 데이터 때문에 늘 1 인 경우가 그렇다.
- 원본 쪽 출력 중 **바뀔 때만 오는 갱신**은 캡처가 어긋나기 쉽다. 해시처럼 매번 오는 값으로 대조하는 것이 기본이다.
