# 공통절차

상위: [PD](PD.md)

## 이 노트

### 요약

- 방향 노트다. 기본값과 이유를 준다.
- 판단 대상이 아닌 것은 [원칙](원칙.md) 에만 있다.
- 역할이 없는 문서다. 지식 담당자 · 이관 담당자 · PD 누구나 쓴다.
- 측정 · 캡처 · 감사 · 컴파일 판정을 할 때 연다. 원본에서 사양을 캐낼 때도 연다.
- 사고 사례와 막는 장치는 [함정 색인](함정%20색인.md) 에 있다.

## 측정 준비

### 요약

- 재기 전에 양쪽 상태를 맞춘다. 상태가 다르면 결함을 가를 수 없다.
- 세이브 백업 · 폰트 로드 대기 · 기능 부재 증명 · A/B 측정 · 기저 상태가 여기 있다.
- 원본 결정성 확인 · 프레임 정지 · 하네스 초기화도 여기 있다.
- 정본은 [공통절차 - 측정 준비](공통절차%20-%20측정%20준비.md).

## 원본 관측 도구

### 요약

- 도구가 입력을 바꿔 버린다. 도구가 되는지 착수 때 한 번 찔러 보고 확정표 13 에 적는다.
- 렌더 대조는 원본 복사본을 결정적으로 만든 뒤에야 뜻이 있다.
- 대기 수단과 node 틱 정답지도 여기 있다.
- 정본은 [공통절차 - 원본 관측 도구](공통절차%20-%20원본%20관측%20도구.md).

## 캡처와 덤프

### 요약

- 캡처에서 읽은 값은 사양이 아니다. 남기는 것은 덤프다.
- 판정 순서는 ①원본 코드 → ②규약 문서 → ③덤프다. 캡처는 그 뒤 눈 확인 한 장이다.
- 요소 대조 · 지표 선정 · 점수 검증 · 채록 위생이 여기 있다.
- 정본은 [공통절차 - 캡처와 덤프](공통절차%20-%20캡처와%20덤프.md).

## 원본에서 값 캐기

### 요약

- URL 제공형 심화다. 좌표로 안 풀리는 물음은 보는 자리를 바꿔 푼다.
- 순서는 ⓪-a 열어서 해 보기 → ⓪ 번들 소스 → ① 후킹 → ② 자산 → ③ 입력값 → ④ 무작위 → ⑤ 저작값 → ⑥ 사건 프레임 덤프다.
- 정본은 [공통절차 - 원본에서 값 캐기](공통절차%20-%20원본에서%20값%20캐기.md).

## 원본 코드 읽기

### 요약

- 함수명과 CSS 클래스명은 원본마다 다르다. 모양만 쓰고 이름은 그 원본의 것으로 바꾼다.
- 라인 번호는 믿지 않는다. 인용할 때마다 grep 으로 확정한다.
- 구간 담당 표는 그 프로젝트 원장에 만든다.
- 정본은 [공통절차 - 원본 코드 읽기](공통절차%20-%20원본%20코드%20읽기.md).

## 에디터 실행

### 요약

- 사람에게 엔진 조작을 요구하지 않는다.
- 에디터가 열려 있으면 끄지 않고 다리로 시킨다. 배치모드는 예외 경로다.
- 끄는 절차와 재부팅 문구가 정해져 있다.
- 정본은 [공통절차 - 에디터 실행](공통절차%20-%20에디터%20실행.md).

## 컴파일 판정

### 요약

- 에디터 없이 임시 프로젝트로 직접 컴파일하면 판정이 된다.
- 「에디터가 새 코드를 안 먹는다」의 첫 번째 용의자는 컴파일 에러다.
- 작업 시작 전에 재생을 한 번 멈춘다.
- 정본은 [공통절차 - 컴파일 판정](공통절차%20-%20컴파일%20판정.md).

## 에셋 등록 감사

### 요약

- 동기화 도구는 「파일 → 주소」만 보장한다.
- 반대 방향은 감사 3종으로 본다. 기본 시점은 화면 완료 전이다.
- 기본은 파일을 만드는 생성기가 등록까지 맡는 것이다.

### 설계

| 항목 | 잡는 것 |
|---|---|
| 코드에 박힌 주소 리터럴 전수 → 등록 여부 | 이름이 어긋난 것 |
| 아트 파일명의 공백·복사본 접미 | 주소를 깨뜨리는 파일명 |
| 등록됐는데 파일이 없는 고아 | 지운 뒤 남은 것 |

- 주의: 감사기는 폴더 엔트리(예: `Enemies/normal`)와 폴더 접두어를 오탐한다. 디렉터리 예외를 넣는다. 폴더면 실제 장수를 센다. 접두어는 Play Mode 로딩으로 확인한다.
- 사례: `Intro_start 1.mp4` 로 주소가 어긋나 `InvalidKeyException` 이 났다. 그때 동기화 도구는 「제거 0 · 건너뜀 0」이었다.
