# 장르 지도

장르와 표현 방식별로 더 볼 것을 모은 색인이다.

## 폴더 범위

### 요약

- 공통 노트(`20 지식` · `40 규약`)는 어떤 게임에도 쓰는 규칙이다.
- 장르와 표현 방식이 달라지면 더 봐야 할 질문, 프리팹 · 데이터 · 재생 계층 구조, 함정이 달라진다.
- 이 폴더는 그 차이만 모은다.

### 규칙

- 방향 노트다. 기본값과 이유를 준다. 판단 대상이 아닌 것은 [원칙](원칙.md) 에만 있다.

## 장르 판정

### 요약

- 기본은 이관 착수 때 두 축을 따로 판정하는 것이다.
- 이유: 한 게임은 두 축에서 노트를 하나씩 가질 수 있다.
- 판정 근거는 `50 공통/` [분석로직 - 학습 판정](분석로직%20-%20학습%20판정.md) 「시스템 축 점검표」와 [PD - 원본 형태](PD%20-%20원본%20형태.md) 「원본 형태 판정」의 결과다.

### 규칙

- #강제 [원칙 R3](원칙.md#R3) 장르 지식으로 원본 사실을 채우지 않는다. 노트는 질문을 주고, 답은 원본에서 잰다.

### 설계

| 축 | 가르는 질문 | 예 |
|---|---|---|
| 장르 (플레이 구조) | 한 판이 무엇으로 굴러가나. 대량 개체 전투 · 격자 판정 · 물리 발사 · 경로 추격 · 카드 선택 | 서바이버 · 매치3 · 물리 퍼즐 · 그리드 아케이드 |
| 표현 방식 (그림) | 그림이 무엇으로 되어 있나. 도트 · 벡터/일러스트 · DOM/CSS UI · 3D | 도트 · 일러스트 · UI 위주 |

## 노트 규격

### 요약

- 기본 단위는 노트 하나 = 장르 하나 또는 표현 방식 하나다.
- 파일 이름은 `장르 - <이름>.md` · `표현 - <이름>.md` 다.
- 아래 다섯 가지가 노트의 카테고리다.

### 규칙

- 카테고리 안은 요약 · 규칙 · 설계 차례다 ([노트 형식](노트%20형식.md)).
- 적는 것은 구조 · 질문 · Unity 패턴이 기본이다. 한 게임의 실측 수치(웨이브 초 · 체력 · 속도)는 그 게임의 분석 문서에 있다. 이유: 장르 노트에 적힌 수치는 다음 게임에서 사양처럼 읽힌다.
- 카테고리는 채울 근거가 생겼을 때 쓰는 것이 기본이다. 이유: 빈 칸은 「해당 없음」으로 읽힌다.
- 이관이 끝나면 그 게임에서 새로 필요했던 질문 · 구조 차이를 해당 노트에 올리고 뒷받침 수를 올린다. 뒷받침이 2건 이상이 되면 상태를 「작성」으로 바꾼다.

### 설계

| 카테고리 | 내용 |
|---|---|
| 알아보는 신호 | 원본에서 이 장르 · 표현이라고 판정하는 근거 |
| 더 볼 질문 | 공통 점검표에 더해 이 장르에서만 추가로 묻는 것 |
| Unity 구조 차이 | 공통 규약과 다르게 가는 자리. 프리팹 단위 · 데이터 모양 · 재생 계층 · 물리 · 입력 |
| 함정 | 이 장르에서 반복된 사고. [함정 색인](함정%20색인.md) 항목으로 링크 |
| 뒷받침 | 이 노트를 뒷받침한 이관 게임 수와 이름. 1건이면 전체를 「가설」로 표시 |

## 노트 목록

### 요약

- 장르 축 노트가 5개, 표현 축 노트가 3개다.
- 뒷받침 1건이면 상태가 「가설」이고, 2건 이상이면 「작성」이다.

### 규칙

- 새 게임을 이관하면 맞는 노트에 질문 · 구조 차이를 올리고 뒷받침 수를 올린다.
- 맞는 노트가 없으면 규격대로 새로 만들고 이 표에 한 줄 더한다.
