# 표현 - DOM CSS UI

그림이 DOM 요소와 CSS 로 된 원본에서 더 재고 다르게 짓는 것이다.

## 알아보는 신호

### 요약

- 보이는 것에 이미지 파일이 없고 CSS 속성이 그림을 만든다.
- 배치를 흐름이 정하고 고정 논리 해상도가 없다.
- 게임판이 canvas 여도 HUD 가 DOM 이면 그 부분은 이 노트를 따른다.

### 설계

| 신호 | 무엇이 보이나 |
|---|---|
| CSS 그림 | 보이는 판 · 버튼 · 배지에 이미지 파일이 없고 CSS 에 `background` · `border-radius` · `box-shadow` 가 있다 |
| 흐름 배치 | 배치를 `flex` · `margin` · `padding` 흐름이 정하고 고정 논리 해상도가 없다 |
| 섞인 원본 | 게임판이 canvas 여도 HUD · 버튼 · 덮개가 DOM 이면 그 부분은 이 노트를 따른다 |
| 폰트 | 문구를 웹폰트나 `system-ui` 폰트 스택이 그리고 기호 · 이모지가 섞인다 |

## 더 볼 질문

### 요약

- 무엇이 CSS 로 그려지고 무엇이 이미지 파일인지 가른다.
- 간격이 적힌 값인지 배분이 만든 결과인지 가른다.
- 폰트는 실제 로드 결과와 cmap 을 잰다.

### 설계

| 주제 | 질문 |
|---|---|
| 그리는 수단 | 무엇이 CSS 로 그려지나(그라디언트 · `box-shadow` inset/outer · `border-radius` · `clip-path` · `::before`/`::after`). 무엇이 이미지 파일인가 |
| 전이 | `transition` · `@keyframes` · `:hover` · `:active` 는 각각 무엇을 어떤 시간 · 이징으로 바꾸나. 전이가 안 걸리는 변화는 무엇인가 |
| 간격 | 간격이 적힌 값인가, `space-between` · `gap` · 음수 마진 · 크기 0 요소가 만든 배분인가 |
| 내용 폭 | 내용이 폭을 정하는 상자(`width:auto`)가 있나. 어떤 상태에서 폭이 바뀌나 |
| 반응형 · 겹침 | `flex-wrap` · `%` · `rem` · `vh` · 미디어 쿼리가 있나. `z-index` 덮개는 무엇을 가리나 |
| 배경 | 배경이 `background-repeat` 타일인가, 늘림인가 |
| 폰트 로드 | 요청한 굵기가 실제로 로드됐나, 합성 볼드인가(가설). 측정은 `document.fonts.ready` 뒤인가 |
| 글자 | 문구의 비ASCII 코드포인트 전수가 우리 폰트 cmap 에 있나 |
| 입력 | 입력이 문서 하나에 위임됐나. `alert()` 같은 브라우저 네이티브 UI 가 있나 |

## Unity 구조 차이

### 요약

- DOM 계층과 흐름 배치 좌표는 옮기지 않는다.
- flex 는 LayoutGroup · 앵커로, 배분은 늘어나는 빈 칸으로 옮긴다.
- CSS 로 그린 판은 흰 둥근 사각형 9-slice 를 굽고 색은 `Image.color` 로 준다.
- 폰트는 하나, 폴백 0 이 기본이다.

### 규칙

- #강제 [원칙 R2](원칙.md#R2) DOM 계층과 흐름 배치 좌표는 옮길 대상이 아니다.
- #강제 [원칙 R12](원칙.md#R12) 버림 / 누름 대체 / 드래그 대체는 PD 가 정한다.
- #강제 [원칙 R10](원칙.md#R10) 키운 읽는 것 · 누르는 것과 제거한 기호는 의도된 차이로 적는다.

### 설계

| 자리 | 기본과 이유 |
|---|---|
| 계층 | 기본은 Window / Panel / Component 에 앉히고, `z-index` 는 밴드 판정 근거로만 쓴다 ([UIFramework](UIFramework.md)). 이유: 겹침은 밴드가 한 곳에서 가른다. 계층이 입력 위임 · 겹침 거동을 만들면 그 거동만 따로 옮긴다 |
| 배치 | 기본은 flex 를 LayoutGroup · 앵커로, 배분을 늘어나는 빈 칸 · 음수 간격 · 끄지 않는 빈 요소로 옮긴다 ([UIUX - 레이아웃](UIUX%20-%20레이아웃.md) 「원본 좌표 계산」 · 「CSS 레이아웃 프리미티브는 Unity 와 1:1이 아니다」). 이유: 고정 간격은 폭이 바뀔 때 어긋난다 |
| 화면 방향 | 화면 방향이 바뀌면 기본은 요소 사이 관계만 새로 정하고 요소 안은 배율 하나로 옮긴다. 키울 후보는 읽는 것 · 누르는 것뿐이다 |
| 내용 폭 상자 | 내용 폭 상자는 기본으로 한 상태의 폭으로 굽는 대신 내용 폭 레이아웃으로 둔다(가설). 폭이 상태와 무관하면 고정 폭을 고려한다 |
| CSS 판 | CSS 로 그린 판은 기본으로 흰 둥근 사각형 9-slice 를 굽고 색은 `Image.color` 로 준다. 그림자 · 반투명이 붙은 판은 색까지 굽는다 ([ResourceRule](ResourceRule.md) 「리소스 굽기」 · [PrefabRule - 함정](PrefabRule%20-%20함정.md) 「렌더링」) |
| 전이 | 기본은 `transition` · `:hover` 를 그 속성만 쥐는 최소 트윈 컴포넌트로 두고, 시간 · 배율은 프리팹 필드에 원본 값으로 둔다 ([UIFramework](UIFramework.md) 「UI 연출」 · [Transfer_Artist](Transfer_Artist.md) 「연출 붙이기」). 이유: 칸이 많은 판에 Animator 는 칸 수만큼 쌓인다. 여러 속성을 엮는 `@keyframes` 연출이면 Animator 를 고려한다 |
| 터치 대체 | 터치 타깃이면 `:hover` · `:active` 를 전수로 센다. 누름 대체는 원본 크기 · 시간 · 이징을 쓴다(가설) |
| 폰트 | 기본은 하나, 폴백 0 이다. 이유: 두부 검사가 cmap 하나로 끝난다. 기호 · 이모지는 cmap 을 잰 뒤 스프라이트로 내리거나 제거한다 ([ResourceRule](ResourceRule.md) 「폰트」). 확정표 문구가 한 폰트에 안 담기면 폴백 체인 + cmap 검사를 고려한다 |
| 네이티브 UI | `alert()` 는 기본으로 게임 위 팝업 창으로 옮기고 종료 이벤트를 받는 곳을 센다. 이유: 원본은 닫힐 때까지 흐름을 막는다 |

### 요약

- 폰트 로드 전과 캡처 한 장으로 재는 사고가 가장 많다.
