# 독스 - 프로젝트 도구

게임 프로젝트 바깥에서 돌리는 파이썬 네 개다. 데이터를 만들거나, 수치를 확인하거나, 노트를 맞출 때 편다.

## 핵심 아이디어

### 게임 프로젝트에는 게임만 둔다

도구와 문서를 게임 폴더에 두면 빌드에 딸려 가지도 않으면서 자리만 차지하고, 저장소를 열었을 때 무엇이 게임인지 흐려진다.

그래서 이 폴더가 도구를 가진다. 게임 프로젝트는 `Source`, `Content`, `Config` 뿐이다.

### 생성물은 저장소에 남고 생성기는 여기 남는다

`gen_skill_tables.py` 가 만든 CSV 는 게임의 데이터라 `Content/Data` 에 있다. 만든 스크립트는 여기 있다.

데이터를 고칠 일이 생기면 여기서 돌리고, 나온 CSV 만 게임으로 간다.

## 구조

| 도구 | 하는 일 | 언제 |
|---|---|---|
| `setup_assets.py` | 빈 맵 두 장을 만들고 스킬 CSV 를 DataTable 로 가져와 GameInstance 에 연결 | 프로젝트를 새로 받았을 때 한 번 |
| `gen_skill_tables.py` | 스킬 트리 CSV 세 장을 만든다 | 트리 모양을 고칠 때 |
| `balance_report.py` | 만렙 스탯과 스테이지 곡선을 계산해 표로 찍는다 | 수치를 고친 뒤 |
| `sync_wiki_code.py` | 노트의 코드 토글을 지금 소스로 채운다 | 코드를 고친 뒤 |
| `ue_remote.py` | 켜져 있는 에디터 안에서 파이썬이나 콘솔 명령을 돌린다 | 에디터를 끄지 않고 무엇을 바꿀 때 |
| `apply_quality.py` | 화질을 최고로 맞추고 저장한다. `ue_remote.py --file` 로 넘긴다 | 화면이 뿌옇게 보일 때 |

### 돌리는 법

```bash
cd C:\jinhyeong_project\UE5_RollBall

"C:\Program Files\Epic Games\UE_5.7\Engine\Binaries\Win64\UnrealEditor-Cmd.exe" RollBall.uproject -run=pythonscript -script="C:\jinhyeong_project\Jinhyeong_Obsidian\Dev_Unreal\90 도구\setup_assets.py"

python "C:\jinhyeong_project\Jinhyeong_Obsidian\Dev_Unreal\90 도구\gen_skill_tables.py"
python "C:\jinhyeong_project\Jinhyeong_Obsidian\Dev_Unreal\90 도구\balance_report.py"
python "C:\jinhyeong_project\Jinhyeong_Obsidian\Dev_Unreal\90 도구\sync_wiki_code.py"
```

`setup_assets.py` 만 언리얼 안에서 돈다. 에셋을 만들려면 에디터의 에셋 체계가 필요하기 때문이다. 나머지 셋은 그냥 파이썬이다.

### 경로가 스크립트 안에 박혀 있다

넷 다 위쪽에 게임 프로젝트와 노트 폴더의 절대 경로를 들고 있다. 프로젝트를 옮기면 거기만 고친다.

`sync_wiki_code.py` 는 두 곳을 본다. 게임 프로젝트의 소스와 이 폴더의 스크립트 둘 다 노트에 붙일 수 있어야 하기 때문이다.

### 켜진 에디터에 명령을 넣는다

에디터를 끄고 켜면 작업 흐름이 끊긴다. 파이썬 플러그인의 원격 실행을 켜 두면 밖에서 켜진 에디터 안으로 파이썬을 보낼 수 있다.

```ini
[/Script/PythonScriptPlugin.PythonScriptPluginSettings]
bRemoteExecution=True
```

이 설정은 에디터가 켜질 때 읽는다. 그러니 켠 뒤 딱 한 번은 에디터를 다시 열어야 한다. 그 뒤로는 끄지 않고 다 한다.

```bash
python ue_remote.py --list
python ue_remote.py --cmd "r.ScreenPercentage 100"
python ue_remote.py --file apply_quality.py
```

콘솔 명령 `LiveCoding.Compile` 도 이 통로로 보낼 수 있다. 함수 몸통만 바꾼 C++ 는 에디터를 끄지 않고 반영된다. 헤더나 `UPROPERTY` 를 바꾼 것은 라이브 코딩이 못 받으므로 그때는 에디터를 닫고 빌드한다.

# -*- coding: utf-8 -*-
"""Makes the assets that cannot be made from C++, without opening the editor.

Run it headless:

    UnrealEditor-Cmd.exe RollBall.uproject -run=pythonscript -script="Tools/setup_assets.py"

It creates the two empty maps the game travels between, imports the three
skill tables, and points the GameInstance Blueprint at them. Running it twice
is safe: anything already there is left alone.
"""

import unreal

CONTENT = "/Game"
MENU_MAP = CONTENT + "/L_MainMenu"
STAGE_MAP = CONTENT + "/L_Stage_01"

DATA_DIR = CONTENT + "/Data"
CSV_DIR = unreal.Paths.project_content_dir() + "Data/"

TABLES = [
    ("DT_SkillDef", "DT_SkillDef.csv", "RollBallSkillDefRow"),
    ("DT_SkillPlacement", "DT_SkillPlacement.csv", "RollBallSkillPlacementRow"),
    ("DT_SkillEdge", "DT_SkillEdge.csv", "RollBallSkillEdgeRow"),
]

assets = unreal.EditorAssetLibrary
levels = unreal.get_editor_subsystem(unreal.LevelEditorSubsystem)


def make_empty_map(path):
    """An empty level. The arena builds its own floor and lighting, so there
    is nothing to place here by hand."""
    if assets.does_asset_exist(path):
        unreal.log("이미 있음: " + path)
        return False

    levels.new_level(path)
    unreal.log("맵 만듦: " + path)
    return True


def import_table(name, csv_name, row_struct_name):
    target = DATA_DIR + "/" + name
    if assets.does_asset_exist(target):
        unreal.log("이미 있음: " + target)
        return

    row_struct = unreal.load_object(None, "/Script/RollBall." + row_struct_name)
    if row_struct is None:
        unreal.log_error("행 구조체를 못 찾음: " + row_struct_name)
        return

    factory = unreal.CSVImportFactory()
    factory.automated_import_settings.import_row_struct = row_struct

    task = unreal.AssetImportTask()
    task.filename = CSV_DIR + csv_name
    task.destination_path = DATA_DIR
    task.destination_name = name
    task.factory = factory
    task.automated = True
    task.replace_existing = True
    task.save = True

    unreal.AssetToolsHelpers.get_asset_tools().import_asset_tasks([task])
    unreal.log("표 가져옴: " + target)


def assign_tables_to_game_instance():
    """Puts the three tables on the GameInstance Blueprint so the packaged
    game finds them. The C++ CSV fallback only runs in the editor."""
    blueprint = assets.load_asset("/Game/BP/BP_RollBallGameInstance")
    if blueprint is None:
        unreal.log_warning("BP_RollBallGameInstance 를 못 찾음")
        return

    defaults = unreal.get_default_object(blueprint.generated_class())
    if defaults is None:
        unreal.log_warning("기본 오브젝트를 못 읽음")
        return

    pairs = [
        ("skill_definition_table", "DT_SkillDef"),
        ("skill_placement_table", "DT_SkillPlacement"),
        ("skill_edge_table", "DT_SkillEdge"),
    ]

    for prop, name in pairs:
        table = assets.load_asset(DATA_DIR + "/" + name)
        if table is None:
            continue
        try:
            defaults.set_editor_property(prop, table)
            unreal.log("%s = %s" % (prop, name))
        except Exception as error:
            unreal.log_warning("%s 설정 실패: %s" % (prop, error))

    assets.save_asset("/Game/BP/BP_RollBallGameInstance")


def main():
    for name, csv_name, row_struct in TABLES:
        import_table(name, csv_name, row_struct)

    assign_tables_to_game_instance()

    # Maps last: creating one opens it, which would drop whatever else is
    # half done.
    make_empty_map(STAGE_MAP)
    make_empty_map(MENU_MAP)

    unreal.log("끝")


main()

# -*- coding: utf-8 -*-
"""Runs Python or console commands inside an editor that is already open.

The editor has to have remote execution on. The project turns it on in
Config/DefaultEngine.ini, so any editor started after that listens.

    python ue_remote.py --cmd "r.ScreenPercentage 100"
    python ue_remote.py --py "print(unreal.SystemLibrary.get_project_directory())"
    python ue_remote.py --file some_script.py
    python ue_remote.py --list
"""

import argparse
import sys
import time

ENGINE_PYTHON = r"C:\Program Files\Epic Games\UE_5.7\Engine\Plugins\Experimental\PythonScriptPlugin\Content\Python"
PROJECT_NAME = "RollBall"

sys.path.insert(0, ENGINE_PYTHON)
import remote_execution as rex


def connect(wait_seconds):
    remote = rex.RemoteExecution(rex.RemoteExecutionConfig())
    remote.start()

    node = None
    deadline = time.time() + wait_seconds
    while time.time() < deadline and node is None:
        for candidate in remote.remote_nodes:
            if candidate.get("project_name") == PROJECT_NAME:
                node = candidate
                break
        time.sleep(0.2)

    return remote, node


def run(remote, node, code, as_statement):
    remote.open_command_connection(node["node_id"])
    try:
        mode = rex.MODE_EXEC_STATEMENT if as_statement else rex.MODE_EXEC_FILE
        result = remote.run_command(code, unattended=True, exec_mode=mode)
    finally:
        remote.close_command_connection()
    return result


def main():
    parser = argparse.ArgumentParser()
    group = parser.add_mutually_exclusive_group(required=True)
    group.add_argument("--cmd", help="console command")
    group.add_argument("--py", help="python statement")
    group.add_argument("--file", help="python file to run")
    group.add_argument("--list", action="store_true", help="list editors that answer")
    parser.add_argument("--wait", type=float, default=4.0)
    args = parser.parse_args()

    remote, node = connect(args.wait)

    try:
        if args.list:
            for candidate in remote.remote_nodes:
                print(candidate.get("project_name"), candidate.get("node_id"))
            return 0

        if node is None:
            print("켜진 에디터를 못 찾았다. 원격 실행이 켜진 채로 열렸는지 본다.")
            return 1

        if args.cmd is not None:
            code = "import unreal\nunreal.SystemLibrary.execute_console_command(None, %r)" % args.cmd
            result = run(remote, node, code, as_statement=False)
        elif args.py is not None:
            result = run(remote, node, "import unreal\n" + args.py, as_statement=False)
        else:
            with open(args.file, encoding="utf-8") as handle:
                result = run(remote, node, handle.read(), as_statement=False)

        for line in result.get("output", []):
            print(line.get("output", "").rstrip())

        if not result.get("success", False):
            print("실패:", result.get("result"))
            return 1

        return 0
    finally:
        remote.stop()


if __name__ == "__main__":
    sys.exit(main())

# -*- coding: utf-8 -*-
"""Fills the code toggles in the Dev_Unreal notes with the current source.

A note marks a slot like this:

    <!-- code: Source/RollBall/Skill/RollBallSkillGraph.h -->
    <!-- /code -->

Everything between the two markers is replaced with a details block holding
the file as it is right now. Run this after changing the source, so the wiki
never drifts away from the code.
"""

import io
import os
import re
import sys

# Code can live in the game project or beside the notes. The tools sit
# here so the game project holds nothing but the game.
SOURCE_ROOTS = [
    r"C:\jinhyeong_project\UE5_RollBall",
    r"C:\jinhyeong_project\Jinhyeong_Obsidian\Dev_Unreal",
]
NOTES_ROOT = r"C:\jinhyeong_project\Jinhyeong_Obsidian\Dev_Unreal"

LANGUAGE_BY_SUFFIX = {
    ".h": "cpp",
    ".cpp": "cpp",
    ".cs": "csharp",
    ".py": "python",
    ".csv": "csv",
    ".md": "markdown",
    ".ini": "ini",
}

OPEN = re.compile(r"<!-- code: ([^()<>]+?) -->")
CLOSE = "<!-- /code -->"


def block_for(relative_path):
    full = None
    for root in SOURCE_ROOTS:
        candidate = os.path.join(root, relative_path.replace("/", os.sep))
        if os.path.isfile(candidate):
            full = candidate
            break

    if full is None:
        return None, "파일 없음: " + relative_path

    text = io.open(full, encoding="utf-8-sig").read().rstrip("\n")
    language = LANGUAGE_BY_SUFFIX.get(os.path.splitext(full)[1], "")
    name = os.path.basename(full)
    lines = text.count("\n") + 1

    body = [
        "<details>",
        "<summary>%s (%d줄)</summary>" % (name, lines),
        "",
        "```" + language,
        text,
        "```",
        "",
        "</details>",
    ]
    return "\n".join(body), None


def fenced_ranges(text):
    """Character ranges inside ``` fences.

    A note that explains the marker shows it as an example inside a fence.
    Filling that one would paste a whole file into the explanation.
    """
    ranges = []
    open_at = None
    position = 0

    for line in text.splitlines(True):
        if line.lstrip().startswith("```"):
            if open_at is None:
                open_at = position
            else:
                ranges.append((open_at, position + len(line)))
                open_at = None
        position += len(line)

    if open_at is not None:
        ranges.append((open_at, len(text)))

    return ranges


def sync(note_path):
    original = io.open(note_path, encoding="utf-8").read()
    skip = fenced_ranges(original)
    out = []
    index = 0
    filled = 0
    problems = []

    while True:
        match = OPEN.search(original, index)
        if match is None:
            out.append(original[index:])
            break

        if any(start <= match.start() < end for start, end in skip):
            out.append(original[index:match.end()])
            index = match.end()
            continue

        close_at = original.find(CLOSE, match.end())
        if close_at == -1:
            problems.append("닫는 표시가 없다: " + match.group(1))
            out.append(original[index:])
            break

        block, error = block_for(match.group(1))
        if error is not None:
            problems.append(error)
            out.append(original[index:close_at])
            index = close_at
            continue

        out.append(original[index:match.end()])
        out.append("\n" + block + "\n")
        index = close_at
        filled += 1

    result = "".join(out)
    if result != original:
        io.open(note_path, "w", encoding="utf-8", newline="\n").write(result)

    return filled, problems


def main():
    if not os.path.isdir(NOTES_ROOT):
        print("노트 폴더가 없다: " + NOTES_ROOT)
        return 1

    total = 0
    all_problems = []

    for folder, _, files in os.walk(NOTES_ROOT):
        if ".obsidian" in folder:
            continue
        for name in sorted(files):
            if not name.endswith(".md"):
                continue
            path = os.path.join(folder, name)
            filled, problems = sync(path)
            if filled or problems:
                print("%-44s 코드 %d개" % (name, filled))
            total += filled
            all_problems.extend(problems)

    print("")
    print("채운 코드 블록 %d개" % total)

    for problem in all_problems:
        print("  문제: " + problem)

    return 1 if all_problems else 0


if __name__ == "__main__":
    sys.exit(main())

## 사용 방법

### 프로젝트를 새로 받았을 때

1. C++ 를 빌드한다
2. `setup_assets.py` 를 돌린다
3. 에디터를 열고 Play 를 누른다

손으로 만들 에셋은 없다.

### 노트에 코드를 붙일 때

파일을 붙여 넣지 말고 표시만 남긴다. 형식은 [문서 쓰는 법](문서%20쓰는%20법.md) 코드 토글 절에 있다.

## 함정

### 켜진 뒤에 바꾼 원격 설정은 안 먹는다

`bRemoteExecution` 을 켠 뒤 에디터를 한 번 다시 열어야 통로가 생긴다. `ue_remote.py --list` 가 아무것도 안 찍으면 에디터가 설정보다 먼저 켜진 것이다.

### 에디터 설정은 켜진 동안 파일을 고쳐도 덮어써진다

에디터는 ini 를 메모리에 들고 있다가 종료할 때 통째로 다시 쓴다. 켜진 동안 파일을 고치면 종료 때 옛 값으로 돌아간다.

파이썬의 `set_editor_property` 는 오브젝트 값만 바꾸고 메모리의 ini 는 안 바꾼다. 그래서 지금은 먹지만 다음에 켜면 원래대로다.

메모리의 ini 를 바꾸고 바로 파일로 내보내야 한다. 게임 모듈의 콘솔 명령으로 한다.

```cpp
GConfig->SetBool(TEXT("/Script/UnrealEd.EditorPerformanceSettings"),
    TEXT("bThrottleCPUWhenNotForeground"), false, GEditorSettingsIni);
GConfig->Flush(false, GEditorSettingsIni);
```

```bash
python ue_remote.py --cmd "rollball.EditorThrottle 0"
```

### 라이브 코딩은 창을 띄우지 않고 돈다

`LiveCoding.Compile` 을 원격으로 보내면 켜진 에디터 안에서 컴파일하고 바로 반영한다. 라이브 코딩 설정의 시작 모드가 `AutomaticButHidden` 이면 콘솔 창도 안 뜬다.

`.cpp` 안의 변경은 다 받는다. 새 전역 콘솔 명령을 추가한 것도 받았다. 헤더, `UPROPERTY`, `UFUNCTION`, 새 클래스는 못 받는다. 그때만 에디터를 닫아야 하고, 닫기 전에 사용자에게 묻는다.

결과는 에디터 로그의 `LogLiveCoding` 줄로 본다.

```
LogLiveCoding: Display: Live coding succeeded
```

### 헤드리스에서는 프로파일러를 시작 인자로 켜지 않는다

`-nullrhi` 에 `-csvCaptureFrames` 를 주면 렌더러가 뜨기 전에 레이트레이싱 가능 여부를 묻다가 죽는다. 콘솔 명령 `csvprofile frames=N` 으로 켠다.

그래도 헤드리스의 프레임 기록은 시간 비교에 못 쓴다. 게임 스레드 시간 칸이 0 으로 찍힌다. 풀이 모자랐는지, 오류가 없는지 같은 동작 확인에만 쓴다.

### 플레이 시작은 다음 틱에 된다

`editor_request_begin_play()` 는 요청만 한다. 같은 명령 안에서 바로 게임 월드를 찾으면 아직 없다. 요청을 보내고, 몇 초 기다렸다가 다음 명령에서 게임 월드를 쓴다.

### 콘솔 명령은 어느 월드에 보내는지 정한다

플레이 중인 게임에 명령을 넣으려면 게임 월드를 넘긴다. `None` 을 넘기면 에디터 월드로 간다.

```python
game = unreal.get_editor_subsystem(unreal.UnrealEditorSubsystem).get_game_world()
unreal.SystemLibrary.execute_console_command(game, "rollball.AutoPlay 1")
```

### 게임 코드에는 주석을 두지 않는다

이 프로젝트는 코드에 주석을 남기지 않는다. 왜 그렇게 했는지는 전부 이 볼트가 가진다.

그래서 코드를 고칠 때 판단이 갈린 자리가 있으면 노트에 적는다. 코드에만 적으면 다음 정리에서 지워진다.
