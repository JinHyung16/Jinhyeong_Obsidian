# Dev_Unreal 지도

언리얼로 게임을 만들며 쌓는 노트다. 무엇을 찾아야 할지 모를 때 여기서 시작한다.

## 핵심 아이디어

만들면서 배운 것을 그때그때 옮겨 적는다. 다음에 같은 것을 만들 때 처음부터 생각하지 않으려고 둔다.

노트는 두 종류다. 지켜야 할 것은 규칙, 만드는 법은 독스다. 형식은 [문서 쓰는 법](문서%20쓰는%20법.md) 에 있다.

## 구조

| 폴더 | 무엇 |
|---|---|
| 00 시작 | 지도와 형식 |
| 10 기초 | 어느 게임에나 쓰는 것 |
| 20 장르 | 장르별로 어떻게 짜는가 |
| 30 UI | 화면 만드는 법 |
| 40 기능 | 기능 하나를 통째로 |
| 50 프로젝트 | 지금 만드는 게임의 기획과 상태 |
| 90 도구 | 프로젝트 바깥에서 돌리는 스크립트 |

## 사용 방법

### 새 노트를 더할 때

1. [문서 쓰는 법](문서%20쓰는%20법.md) 에서 성격을 고른다
2. 폴더를 고른다. 어느 게임에나 쓰면 기초, 이 게임에만 쓰면 프로젝트다
3. 이름은 `독스 - 주제` 나 `규칙 - 주제` 로 짓는다
4. 이 노트의 노트 절에 한 줄을 더한다

### 코드를 고친 뒤

```bash
python "90 도구/sync_wiki_code.py"
```

노트 안의 코드 토글이 지금 코드로 바뀐다.
