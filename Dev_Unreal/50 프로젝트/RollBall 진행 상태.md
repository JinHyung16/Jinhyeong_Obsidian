# RollBall 진행 상태

무엇이 됐고 무엇이 남았는지 적는다. 다음에 무엇을 할지 고를 때 편다.

## 핵심 아이디어

게임 프로젝트에는 게임만 둔다. 기획도 기술 문서도 도구도 전부 이 볼트가 가진다.
코드에는 주석을 두지 않는다. 왜 그렇게 짰는지는 여기 적는다.

순서는 아래로 간다. 앞이 끝나야 뒤가 의미가 있다.

```
스킬 트리   골드를 쓸 곳이 있어야 골드가 의미를 가진다
   v
생존 루프   골드가 나오는 곳
   v
적과 보스   버틸 상대
   v
무기        스킬로 찍은 것이 화면에 보이는 자리
```

## 구조

### 된 것

| 부분 | 어디 |
|---|---|
| 스킬 그래프 규칙과 계산 | `Source/RollBall/Skill/RollBallSkillGraph.cpp` |
| 스킬 데이터 세 장 | `Content/Data/DT_Skill*.csv` |
| 스킬 트리 화면 | `Source/RollBall/UI/RollBallSkillGraphWidget.cpp` |
| 계정 저장, 골드, 환생, 계정 삭제 | `Source/RollBall/Game/RollBallGameInstance.cpp` |
| 스테이지 공식 100판 | `Source/RollBall/Stage/RollBallStageTypes.h` |
| 생존 루프, 구간 전환, 결과 | `Source/RollBall/Game/RollBallGameModeBase.cpp` |
| 적 네 종류, 정예, 보스 | `Source/RollBall/Enemy/RollBallEnemy.cpp` |
| 무기 네 종류 | `Source/RollBall/Weapon/RollBallWeaponComponent.cpp` |
| 공 스탯, 피해, 사망 | `Source/RollBall/Game/RollBallPlayer.cpp` |

만드는 법은 [독스 - 생존 루프](독스%20-%20생존%20루프.md) 에 있다.

### 에디터에서 손으로 할 일은 없다

표를 가져오는 것도 맵을 만드는 것도 파이썬이 한다.

```bash
UnrealEditor-Cmd.exe RollBall.uproject -run=pythonscript -script="<볼트>/90 도구/setup_assets.py"
```

두 번 돌려도 안전하다. 이미 있는 것은 건드리지 않는다.

### 남은 것

| 순서 | 부분 | 걸린 것 |
|---|---|---|
| 1 | 펩 에셋 | 5개 모두 라이브러리에 있다. 돌 팩만 프로젝트에 들어왔다. 나머지 4개는 언리얼 전용이라 런처로 넣는다 |
| 2 | 풀링 전후 ms 비교 | 에디터 안에서 `stat unit` 으로 잰다. 사용자가 플레이 중이 아닐 때 묻고 한다 |
| 3 | 아트 | 사용자가 언리얼 에셋스토어에서 고른다 |

소리는 하지 않기로 했다.

C++ 로 만들 것은 한 바퀴 돌았고 수치도 계산으로 맞췄다.
계산 결과는 [독스 - 밸런스 곡선](독스%20-%20밸런스%20곡선.md) 에 있다.
