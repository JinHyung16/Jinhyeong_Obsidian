# RollBall 기획

지금 만드는 게임이 무엇인지 적는다. 기능을 설계하기 전에 편다.

## 핵심 아이디어

공을 굴려 다가오는 적에게서 버티는 게임이다. 져도 골드를 얻고, 그 골드로 스킬을 찍어 다시 들어간다.

실패가 손해가 아니라 진전이다. 그래서 계속 도전하게 된다.

## 구조

### 한 판

| | 값 |
|---|---|
| 조작 | WASD 로 공을 굴린다 |
| 죽는 조건 | 적에게 피해를 입으면 |
| 한 스테이지 | 12분 |
| 마지막 2분 | 정예 몬스터 |
| 보스 | 5스테이지마다 마지막에 |
| 끝 스테이지 | 100 |

적을 잡을 때마다 골드가 떨어진다. 클리어와 실패에 관계없이 결과 화면이 뜨고 다음 스테이지로 넘어간다.

### 환생

```
환생 보상 = 최고 도달 스테이지 x 스테이지당 골드 x 환생 배수
```

환생하면 스킬이 전부 초기화된다. 최고 도달 스테이지와 환생 횟수는 남는다.

자주 환생해 강해지고 더 깊은 스테이지를 깨는 것이 목표다.

### 맵

크기만 다른 사각형을 이어 붙인 단순한 모양이다. 오르막과 내리막이 있다.

아트 리소스가 없어 기본 3D 도형과 색으로 대신한다.

### 장애물

| 장애물 | 하는 일 |
|---|---|
| 나무 | 길을 막는다 |
| 굴러오는 공 | 플레이어를 밀친다 |
| 원통 적 | 플레이어에게 돌진한다 |
| 운석 | 위에서 아래로 떨어진다 |

### 무기

스킬로 찍어 판에 들고 들어간다.

| 무기 | 자리 | 강화하면 |
|---|---|---|
| 헤머 | 공 주변을 돈다 | 최대 4개까지 늘어난다 |
| 전기톱 | 공 앞 | 크기가 커진다. 최대 공의 2배 |
| 불도저 | 공 앞 | 폭이 넓어지고 더 밀어낸다 |
| 드릴 | 공 앞 | 만렙이면 공 위쪽에 하나 더 |

무기에 따라 공이 구를 때 같이 도는 것과 안 도는 것이 있다.

### 스킬

노드 하나가 능력치 하나를 조금씩 준다. 그래야 트리로 길게 이어 강화하는 모양이 나온다.

1회 찍고 만렙인 노드와 5회까지 찍는 노드가 섞여 있다.

만드는 법은 [독스 - 스킬 트리 만드는 법](독스%20-%20스킬%20트리%20만드는%20법.md) 에 있다.

### 메인 화면

- 게임 이름
- 게임 시작
- 스킬 트리
- 계정 삭제. 누르면 메인 화면을 다시 불러 새로 시작한다

### 밸런스 기준

- 별의 위치는 맵마다 늘 무작위다
- 제한 시간은 맵 난이도에 비례해 조금씩 늘어난다
- 획득량도 난이도에 비례해 조금씩 늘어난다
- 늘어난 제한 시간보다 늘어난 획득량이 더 크면 안 된다. 그러면 시간이 늘어난 느낌이 안 난다
