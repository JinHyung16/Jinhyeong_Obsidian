# 단계 4 - UI

바인딩 계약 → 골격 클래스 → 프리팹 굽기 → 촬영. 스펙 계약 절에 화면별 바인딩 계약이 있고 UI 조각이 준비됐을 때 편다.
기본은 프리팹을 손으로 만들지 않고 빌더로 굽는 것이다. 계약이 곧 빌더가 만드는 노드 이름 표다. 규약은 문서보다 상속이 지키므로 베이스 클래스가 먼저다.

| 칸 | 내용 |
|---|---|
| 받는 것 | 스펙 계약 절 화면별 바인딩 계약 · `_Ref/<게임>/ui.tsv` · 스펙 확정표 절 3·6·7행 · `Assets/_Art/UI/**` 조각 |
| 읽을 노트 | [규약 - UI](규약%20-%20UI.md) · [규약 - 프리팹](규약%20-%20프리팹.md) · [양식 - UI 프리팹](양식%20-%20UI%20프리팹.md) · [규약 - 플랫폼](규약%20-%20플랫폼.md) |
| 내는 것 | `Assets/_Art/Prefabs/UI/*.prefab` · Addressable 그룹 `UI` 등록 · 화면별 캡처 `Temp/*.png` · `Temp/editor.task.log`(ui) |
| 게이트 | G8 프리팹 용량 예산 · 열린 화면 외 로드 0 · 바인딩 계약 위반 0(노드명·필드명) · 양식 노드 검사 0(SafeArea·Container·Dim·Body) · 캡처에 겹침·잘림 0 |

## 하는 일

읽을 노트에서 볼 곳:

- [규약 - UI](규약%20-%20UI.md) 전체
- [규약 - 프리팹](규약%20-%20프리팹.md) 전체
- [양식 - UI 프리팹](양식%20-%20UI%20프리팹.md) 전체
- [규약 - 플랫폼](규약%20-%20플랫폼.md) 해상도·세이프에리어

1. 화면마다 `WindowType` 을 배정한다. `ui.tsv` 의 화면 종류·정보량 → 확정표 6행. 종류는 HUD·Normal·Popup·Modal·GlobalPopup 다섯.
   슬라이스 화면만 한다 — 장르 노트가 "HUD 1 + 선택 팝업 1 + 결과 1"이라 하면 그 셋이다
2. 패키지가 깔렸는지 본다. `com.jinhyung.gameframework` 가 manifest 에 있고 컴파일 0 인가 ([규약 - 패키지](규약%20-%20패키지.md)).
   베이스 클래스는 패키지가 주므로 직접 만들지 않는 게 기본이다 ([함정 66](함정%20-%20구조%20설계.md))
3. 화면 클래스 골격을 쓴다. `BaseWindow` 를 상속하고 `OnOpening()` 에서 채우고 `OnClose()` 에서 비운다. 등록은 `BaseManagement.AddWindows()`. `Awake`·`Start` 에 논리 0.
   경로 상수는 그 클래스가 든다 (`XxxWindow.PrefabPath`)
4. 빌더에 화면당 함수 하나를 더한다. 첫 줄은 양식 루트 헬퍼다 — Window 는 `MakeWindowRoot`, Popup 은 `MakePopupRoot` ([양식 - UI 프리팹](양식%20-%20UI%20프리팹.md)).
   그 아래에만 고정 요소·Container 를 계약 표 그대로 둔다. 같은 경로에 덮어써 GUID 를 유지한다. 반복 요소는 코드 + 풀
5. `Temp/editor.task` ← `ui`. 로그에서 `sprite.border` 실측값과 GUID 끊김 검사를 읽는다
6. 촬영한다. `Temp/runloop.request` ← `god:15:1:<화면>` 으로 화면마다 1280×720 캡처
7. 겹침·잘림·글리프를 캡처에서 확인한다. 세이프에리어 밖 0 · 텍스트 잘림 0 · 네모 글리프 0

## 막혔을 때

| 상황 | 하는 일 |
|---|---|
| 계약에 없는 노드가 필요 | 계약 변경이다. 스펙 계약 절을 고치고 빌더도 같이 고친다. 프리팹만 고치면 다음 굽기에 날아간다 |
| `ui.tsv` 가 미측정 (정보량·동선) | 화면당 정보 7±2 · 종류는 HUD/Normal/Popup 셋으로 시작. 채우고 스펙 추정 절에 적는다. 비용: "해당 화면 재배치" |
| 받은 UI 스프라이트의 9슬라이스 경계가 의심 | 알파를 훑어 실측한다. 경계는 코드에 적지 않고 `sprite.border` 에서 읽는 게 기본이다 ([함정 50](함정%20-%20UI%20표시.md)) |
| 현행 빌더가 데이터 주도가 아니다 | 기본 규약은 화면당 빌더 함수 1개다. 화면 목록 → 프리팹 자동 생성은 큐 하단 "슬라이스 밖" |

## 자주 틀리는 것

- 화면비만 바꾸고 폰트 크기를 안 바꾼다 — 글자가 2.7배가 된다 (1080×1920 → 1280×720)
- 테두리 장식을 레이아웃 그룹 안에 얹어 칸을 하나 차지한다. `ignoreLayout` 으로 뺀다
- 원형을 9슬라이스로 붙여 캡슐이 된다
- Resources 에 "나중에 쓸지도"를 둔다. 참조가 없어도 빌드에 통째로 들어간다
- "런타임에 숨긴 것"을 "없앤 것"으로 센다. 프리팹을 실제로 비운다
