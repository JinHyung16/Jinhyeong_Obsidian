# 단계 6 - QA

확정표 vs 실측 → 위반 목록 → 되돌림. 단계 5 가 하네스 리포트와 캡처를 낸 뒤, 만든 것이 확정표대로인지 판정할 때 편다.
개발 파이프라인을 뒤집은 단계다. 확정표가 "무엇이어야 하나", 하네스가 "실제로 어떤가"를 들고, 둘을 행 단위로 대조해 위반 목록을 낸다. 위반은 큐로 돌아가 단계 5가 다시 돈다.

| 칸 | 내용 |
|---|---|
| 받는 것 | 스펙 확정표 절, 하네스 절 · `Temp/runloop.report` · `runloop_*.png` · 회귀 기준표(있으면) |
| 읽을 노트 | [역할 - PD](역할%20-%20PD.md) · [양식 - 하네스](양식%20-%20하네스.md) · [규약 - 최적화](규약%20-%20최적화.md) · [역할 - 아트](역할%20-%20아트.md) |
| 내는 것 | 스펙 QA 절, 실측 기준 절(갱신), 실측 기준 절(회귀) |
| 게이트 | G5 회귀 · G6 성능(4행 예산) · G9 뷰 · 위반 0 또는 되돌림 한도 도달 시 보고 |

## 하는 일

읽을 노트에서 볼 곳:

- [역할 - PD](역할%20-%20PD.md) 게이트 G0~G9
- [양식 - 하네스](양식%20-%20하네스.md) 전체 · "실측이 숫자를 내놓아도 의심한다"
- [규약 - 최적화](규약%20-%20최적화.md) 측정법
- [역할 - 아트](역할%20-%20아트.md) 숫자 판정

1. 13행을 판정 문장으로 바꾼다. 행마다 "무엇을 재서 어떤 값이면 통과". 못 바꾸는 행은 [단계 0 - 접수](단계%200%20-%20접수.md) 추출이 틀린 것이다 —
   스펙 추정 절에 "판정 불가 · 재확정 필요"로 적고 그 행은 미측정으로 둔다
2. 필멸 완주를 잰다. `mortal:<세션 길이>` 3회. 지표는 구간 최저 HP 다. 종료 시점 HP 는 스폰이 멈춰 회복되므로 튄다.
   죽는 게 정상인 장르면 클리어율 100% 를 요구하지 않는다
3. 성능을 잰다. 목표 부하(4행 동시 개체 상한) 상태에서 FPS · 드로우콜 · GC. 에디터 값과 빌드 값을 구분해 적는다
4. 룩을 숫자로 잰다. 캡처를 확대해 [역할 - 아트](역할%20-%20아트.md) 4종(외곽선 비중·실루엣 굴곡·접지 그림자·명암 단수) + 뷰(스폰 경계·정렬·세이프에리어).
   브리지가 없어 캡처가 비면 미측정이다 — 통과가 아니다
5. 회귀 기준표를 갱신한다. 이번 실측치가 다음 판의 기준이다. 의도한 변경은 사유를 적고 기준을 바꾼다
6. 위반 목록을 쓴다 → 스펙 QA 절

   [예시]

   ```
   | 행 | 확정값 | 실측값 | 출처 (리포트 키 / 캡처 파일) | 판정 |
   | 10 세션 | 720초 완주 | 615초 사망 (3회 중 1) | runloop.report#survived | 통과 (2/3 클리어, 로그라이크) |
   | 4 성능 | 60FPS @150 | 49FPS @131 (에디터) | runloop.report#fps | 위반 — 빌드 미측정 |
   ```

7. 위반을 큐 하단에 append 하고 [단계 5 - 클라](단계%205%20-%20클라.md) 로 돌린다. 항목 제목은 위반 행, 완료 기준은 그 행의 판정 문장

## 막혔을 때

| 상황 | 하는 일 |
|---|---|
| 같은 행이 3회 되돌림 후에도 위반 | 그 행을 "미달 · 시도 3회"로 스펙 QA 절에 남기고 다음 행으로 간다. [단계 7 - 플레이](단계%207%20-%20플레이.md) 보고에 올린다 |
| 실측치가 확정값과 크게 어긋남 (2배 이상) | 하네스 자체를 먼저 의심한다 — 회피를 하나 · 워치독이 도나 · 플레이어가 두 마리 아닌가. 하네스가 무효면 수치를 고치지 않는다 |
| 회귀 기준표가 없다 (첫 판) | 이번 값이 기준이다. "기준 없음"이라 적고 통과 |
| 밸런스 편차가 큼 (같은 데이터 3회가 갈림) | 수치보다 뽑기를 의심한다. 드랍·초반 보장을 큐 항목으로 |

## 자주 틀리는 것

- 배치모드 리포트로 룩을 통과시킨다. 헤드리스는 화면을 못 본다 — 같은 하네스가 배치 5킬 / GUI 55킬이었다
- 완료 기준을 클리어율 100% 로 쓴다. 로그라이크와 앞뒤가 안 맞는다
- 한 번에 변수 둘을 고친다. 화력이 절반이 된 직후 피해 +15% 와 회복 삭감을 같이 얹어 라운드 7 에서 죽었다
- 실측과 계산을 한 표에 섞는다. 밸런스 기록(스펙 실측 기준 절)은 실측만 담는다
