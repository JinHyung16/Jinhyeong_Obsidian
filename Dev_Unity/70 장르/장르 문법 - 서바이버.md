# 장르 문법 - 서바이버

서바이버류(뱀서라이크)의 문법 · 뷰 · 데이터 축 · 성능 · 함정이다. 장르를 서바이버로 잡았을 때 확정표를 채우기 전에 편다. 규격은 [장르 문법 지도](장르%20문법%20지도.md).

## 문법

- 자동 공격 + 수동 이동. 재미의 축은 "조준"이 아니라 위치 선정과 빌드 선택이다
- 처치 → 드랍 → 성장 → 밀도 상승의 루프가 세션 내내 가속한다

## 뷰·조작

확정표 2·8행의 기본값이다.

- 2D 유사 탑다운(75~85°) 또는 쿼터뷰
- 플레이어는 화면 중앙 고정, 카메라 회전 없음
- 모바일 세로는 플로팅 조이스틱 1개가 표준이다
- Y 정렬을 켜는 것이 기본이다 ([규약 - 뷰](규약%20-%20뷰.md) 유사 탑다운 절)

## 데이터·UI 축

확정표 5·6행의 출발점이다.

- 스킬/증강이 조합형 데이터의 교과서적 사례다 — 발사 방식 × 수치 × 속성
- UI 는 인게임 HUD 1 + 레벨업 선택 팝업 1 + 결과 1이면 루프가 돈다. 밴드 3종으로 시작한다

## 성능 특성

- 동시 개체 수가 지배 변수다. 풀링 · 화면 밖 비용 차단 · 핫패스 무할당이 전제조건이다
- 적 300 이 목표면 개체별 `Update` 구조로는 처음부터 닿지 않는다

## 장르 함정

- 스폰을 화면 안에서 하면 갑툭튀, 너무 밖에서 하면 밀도가 안 찬다. 기본은 화면 경계 바로 밖이다
- 기울인 카메라의 가시 영역은 사다리꼴이다. 원형 스폰 링은 위쪽 편중을 만든다
- 레벨업 선택 중 월드는 완전 정지가 기본이다. 이유: 시간이 흐르면 선택이 벌칙이 된다
- 성장 체감은 "수치 +10%"보다 "발사체 +1 / 신규 스킬"이 크다. 선택지 구성에 반영한다
- 피격 무적이 없으면 프레임레이트가 곧 난이도가 된다
