# 장르 문법 - 타일 전략

육각/사각 타일 전략(SLG · 타일 점령)의 문법 · 뷰 · 데이터 축 · 성능 · 함정이다. 장르를 타일 전략으로 잡았을 때 확정표를 채우기 전에 편다. 규격은 [장르 문법 지도](장르%20문법%20지도.md).

## 문법

- 공간이 자원이다. 타일의 인접 관계가 전투 · 확장 · 경로의 판 자체다

## 뷰·조작

확정표 2·8행의 기본값이다.

- 고정 앵글 쿼터뷰 + 팬/줌 (회전은 대개 없음)
- 탭 = 선택, 롱탭/더블탭 = 정보
- 화면 → 타일 좌표 변환 유틸은 하나만 두는 것이 기본이다

## 데이터·UI 축

확정표 5·6행의 출발점이다.

- 화면 수가 폭발하는 장르다 (건물 · 부대 · 길드 · 상점 · 이벤트 …)
- UI 구조(확정표 6·7행)는 슬라이스에서 정하는 것이 기본이다. 이유: 화면 20개째에는 구조에 손을 못 댄다
- 밴드 8종 규모다. 이 규모에서는 재활용 스크롤과 창 · 조각(Window/Popup/HUD · Component) 분리가 기본이다. 탭 내용은 조각 묶음 또는 별도 창으로 둔다

### 구현

이 장르에서 제일 중요한 분기는 타일을 지형으로 쓸 것인가, 보드로 쓸 것인가다.

| 쓰임 | 규모 · 특징 | 맞는 구현 |
|---|---|---|
| 지형 | 수천 셀, 경계 블렌딩 · 높이차 | 청크 메시 합치기 |
| 보드 | 수십 노드, 개별 선택 · 상태 연출 | 개별 GameObject + 좌표계 유틸 |

보드에 지형용 청크 시스템을 들이면 수천 줄을 헛짐으로 진다.

## 성능 특성

- 개체 수보다 UI 리빌드와 텍스트 갱신이 병목이 되는 드문 장르다

## 장르 함정

- 이동 규칙과 칸 이벤트 규칙의 상호작용(통과 시 발동 × 대량 이동)은 조합 표로 확정하는 것이 기본이다
