# 장르 문법 - 방치

방치 · 클리커(메타 성장 중심)의 문법 · 뷰 · 데이터 축 · 성능 · 함정이다. 장르를 방치로 잡았을 때 확정표를 채우기 전에 편다. 규격은 [장르 문법 지도](장르%20문법%20지도.md).

## 문법

- 세션은 짧고 성장 곡선은 길다
- 숫자 인플레이션 관리가 설계의 본체다

## 뷰·조작

확정표 2·8행의 기본값이다.

- 뷰가 거의 UI다. 월드가 있어도 배경 연출에 가깝다
- UI 구조가 곧 게임 구조다

## 데이터·UI 축

확정표 5·6행의 출발점이다.

- 업그레이드 항목 = 데이터 1건 + 곡선
- 화면은 목록형이 지배적이다. 그래서 재활용 스크롤 + 값 갱신 최소화가 UI 규약의 전부에 가깝다

### 구현

- 큰 수 처리(지수 표기) · 오프라인 경과 정산 · 저장 데이터 마이그레이션을 초기에 넣는 것이 기본이다
- 밸런스 수식은 전부 데이터로 둔다. 이유: 이 장르는 상수 튜닝이 개발의 절반이다

## 성능 특성

- 텍스트 갱신이 유일한 병목이다
- 초당 1회 틱으로 충분한 것은 매 프레임에 두지 않는 것이 기본이다

## 장르 함정

- 오프라인 정산은 "이득 재현"이 아니라 수식 근사가 기본이다. 이유: 실시간 시뮬레이션 재생은 터지지 않는 쪽이 드물다
- 기기 시계 조작을 전제로 설계한다
