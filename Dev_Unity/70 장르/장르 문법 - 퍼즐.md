# 장르 문법 - 퍼즐

퍼즐(매치 · 머지 · 보드)의 문법 · 뷰 · 데이터 축 · 성능 · 함정이다. 장르를 퍼즐로 잡았을 때 확정표를 채우기 전에 편다. 규격은 [장르 문법 지도](장르%20문법%20지도.md).

## 문법

- 규칙은 단순, 상태 공간은 깊게
- 재미의 축은 "읽힘"이다 — 다음 수가 보이는 판

## 뷰·조작

확정표 2·8행의 기본값이다.

- 2D 정면 고정
- 입력 1종(탭 또는 드래그)으로 전부
- 입력 실수가 벌칙이 되지 않게 스왑 취소 · 되돌리기를 두는 것이 기본이다

## 데이터·UI 축

확정표 5·6행의 출발점이다.

- 스테이지 = 데이터 1건 (보드 초기 상태 + 목표 + 제한)
- UI 는 적지만 연출 타이밍이 많다. 그래서 연출 중 입력 잠금 구간이 UI 스펙의 절반이다

### 구현

- 보드 상태는 순수 데이터(2차원 배열)로 두고 뷰는 그걸 그리기만 하는 것이 기본이다. 이유: 로직 · 뷰가 섞이면 연출 타이밍을 바꿀 때마다 규칙이 흔들린다
- 판정이 헤드리스로 시뮬레이션 가능해야 데드락 검사 · 힌트 · 난이도 자동 검증이 나온다

## 성능 특성

- 대체로 여유롭다. 대신 연출 큐가 길어지면 체감이 느려진다

## 장르 함정

- 콤보/연쇄 중 새 입력 허용 여부를 초기에 확정하는 것이 기본이다. 나중에 바꾸면 전 연출을 다시 짜게 된다
