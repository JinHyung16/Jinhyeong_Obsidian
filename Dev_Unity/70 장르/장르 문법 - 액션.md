# 장르 문법 - 액션

액션(근접 · 플랫포머 · 탑다운 슈터)의 문법 · 뷰 · 데이터 축 · 성능 · 함정이다. 장르를 액션으로 잡았을 때 확정표를 채우기 전에 편다. 규격은 [장르 문법 지도](장르%20문법%20지도.md).

## 문법

- 입력 → 반응의 지연이 곧 품질이다
- 선입력 버퍼 · 코요테 타임 같은 관용 처리가 표준이다

## 뷰·조작

확정표 2·8행의 기본값이다.

- 플랫포머는 사이드뷰에 데드존 + 룩어헤드를 두는 것이 기본이다
- 탑다운 슈터는 유사 탑다운 + 조준 축 1개 추가
- 조작 축이 2개(이동 + 조준)면 모바일 UI 설계가 통째로 달라진다

## 데이터·UI 축

확정표 5·6행의 출발점이다.

- 판정 프레임 · 경직 · 무적은 전부 데이터로 두는 것이 기본이다. 이유: 애니 교체가 판정을 바꾸면 안 된다

### 구현

- 상태머신(또는 BT)으로 캐릭터 상태 전이를 명시한다
- 애니메이션 이벤트와 판정 프레임을 분리한다

## 성능 특성

- 개체 수는 적지만 프레임 안정성이 지배 변수다. 튐 하나가 곧 조작 실패다

## 장르 함정

- 히트스톱 · 넉백 · 무적 프레임은 "있냐 없냐"가 아니라 수치 스펙이다
- 물리 기반 이동과 커스텀 이동을 섞으면 경계에서 샌다. 기본은 하나로 통일이다
