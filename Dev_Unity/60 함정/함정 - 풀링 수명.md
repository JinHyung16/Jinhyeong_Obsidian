# 함정 - 풀링 수명

풀에서 재사용한 객체에 이전 수명의 상태나 구독이 남아 2회차부터 오염된 사고다. 풀링 대상 컴포넌트를 쓰거나 리뷰할 때, 풀에서 꺼낸 오브젝트가 이상하게 굴 때 편다.

### 풀 재사용 시 남는 상태
번호: 함정 7
- 증상: 풀에서 꺼낸 오브젝트가 재사용 2회차부터 이상하게 군다.
- 원인: 유도 투사체의 타깃 참조, 라이트 강도를 0까지 깎는 스크립트가 반납 때 되돌려지지 않았다.
- 방향: 기본은 풀링 3법칙(리셋·재구독·복구)을 반납 시점에 적용하는 것이다. 리뷰 때는 OnDisable 부터 본다.
- 관련: [규약 - 최적화](규약%20-%20최적화.md) 풀링 절 · [함정 8](함정%20-%20풀링%20수명.md)

### 재사용 객체의 이벤트 중복 구독
번호: 함정 8
- 증상: 재사용 횟수만큼 핸들러가 쌓여 한 이벤트에 여러 번 반응한다.
- 원인: Spawn 마다 `+=` 만 했다.
- 방향: 기본은 `-=` 후 `+=` 패턴으로 고정하는 것이다.
- 관련: [함정 7](함정%20-%20풀링%20수명.md) · [규약 - 최적화](규약%20-%20최적화.md) 풀링 절
